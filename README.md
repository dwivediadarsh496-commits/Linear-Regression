Introduction
Linear Regression is one of the most basic and important algorithms in Machine Learning. It is mainly used when we want to predict a numeric value such as price, marks, salary, or temperature.

What is Linear Regression?
Linear Regression finds a straight-line relationship between an input (independent variable) and an output (dependent variable).

Example:

Predicting marks based on hours studied
Predicting house price based on area
The relationship looks like a straight line:

Write on Medium
y = mx + c

How It Works
The algorithm tries to draw a best-fit line through data points.
This line minimizes the error between predicted and actual values.
The error is usually calculated using Mean Squared Error (MSE).
Real-Life Example
If a student studies more hours, their marks generally increase. Linear Regression helps predict marks for given study hours.

Applications
Salary prediction
Sales forecasting
Weather prediction
Conclusion
Linear Regression is easy to understand and is the foundation of Machine Learning. Every student should learn it first.
